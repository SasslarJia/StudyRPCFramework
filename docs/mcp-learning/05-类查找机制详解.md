# 05 - 类查找机制详解

## 概述

`find_class()` 方法负责在项目依赖的JAR包中查找指定的类文件。

## find_class() 方法完整流程

```python
def find_class(self, class_path):
    """Find a class file in dependencies by its full path"""
    # 1. 确保依赖已加载
    if not self.dependencies:
        self.load_dependencies()
        
    # 2. 将类路径转换为文件路径
    # com.example.MyClass -> com/example/MyClass.class
    class_file = class_path.replace('.', '/') + '.class'
    
    # 3. 创建临时目录用于提取
    temp_dir = tempfile.mkdtemp()
    
    try:
        # 4. 遍历所有依赖查找类
        for dep_key, dep_info in self.dependencies.items():
            jar_path = dep_info.get('path')
            # ...查找逻辑
    finally:
        # 5. 清理临时目录
        shutil.rmtree(temp_dir)
```

## JAR包内容检查

使用 `jar tf` 命令列出JAR包中的所有文件：

```python
# 使用jar命令检查类是否存在
result = subprocess.run(
    ['jar', 'tf', jar_path],  # tf = table of files
    capture_output=True, 
    text=True
)

jar_contents = result.stdout.splitlines()
if class_file in jar_contents:
    print(f"类在项目依赖中找到: {dep_key} ({jar_path})")
```

## 类文件提取

使用 `jar xf` 命令从JAR包中提取文件：

```python
# 提取类文件到临时目录
extract_result = subprocess.run(
    ['jar', 'xf', jar_path, class_file],  # xf = extract file
    cwd=temp_dir,  # 在临时目录中执行
    capture_output=True
)

if extract_result.returncode == 0:
    extracted_path = os.path.join(temp_dir, class_file)
    # 例如: /tmp/tmpxyz123/org/springframework/core/SpringVersion.class
```

## 临时目录管理

### 为什么需要临时目录？

```
问题: jar xf 命令会在当前目录创建文件夹结构
解决: 使用临时目录，用完后删除

tempfile.mkdtemp()  →  创建: /tmp/tmpxyz123/
                        ↓
                    在此提取文件
                        ↓
shutil.rmtree()     →  删除整个目录
```

### try...finally 确保清理

```python
temp_dir = None
try:
    temp_dir = tempfile.mkdtemp()
    # ... 使用临时目录的操作 ...
finally:
    # 无论成功还是异常，都会执行清理
    if temp_dir and os.path.exists(temp_dir):
        shutil.rmtree(temp_dir)
```

## 关键Python技巧

### 字符串替换转换路径

```python
class_path = "org.springframework.core.SpringVersion"
class_file = class_path.replace('.', '/') + '.class'
# 结果: "org/springframework/core/SpringVersion.class"
```

### subprocess.run 的参数

```python
subprocess.run(
    ['jar', 'tf', jar_path],  # 命令和参数列表
    capture_output=True,       # 捕获stdout和stderr
    text=True,                 # 输出为字符串（而非bytes）
    cwd=temp_dir               # 工作目录
)
```
