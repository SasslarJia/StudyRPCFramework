## 代码模块总结

### 模块1: 导入和初始化

```python
# 标准库
import os          # 文件系统操作
import json        # JSON解析
import subprocess  # 执行外部命令
import tempfile    # 临时文件管理
import shutil      # 文件操作（删除目录）

# 第三方库
from mcp.server.fastmcp import FastMCP  # MCP框架

# XML解析
import xml.etree.ElementTree as ET

# 创建MCP服务器
mcp = FastMCP("maven-class-explorer")
```

### 模块2: MavenClassExplorer 类

| 方法 | 功能 |
|------|------|
| `__init__()` | 初始化配置（工作空间、Maven仓库路径等） |
| `load_dependencies()` | 加载Maven依赖（三种策略） |
| `parse_pom_file()` | 使用 `mvn dependency:list` 解析依赖 |
| `get_effective_pom()` | 使用 `mvn help:effective-pom` 生成完整POM |
| `parse_effective_pom()` | 解析effective POM的XML |
| `read_vscode_classpath()` | 从VSCode配置读取依赖 |
| `find_class()` | 在项目依赖中查找类 |
| `find_in_jar()` | 在指定JAR中查找类 |
| `search_all_repository()` | 在全局Maven仓库中搜索 |
| `_get_jar_path()` | Maven坐标转JAR路径 |
| `_extract_maven_coords()` | JAR路径转Maven坐标 |
| `_decompile_class()` | 反编译.class文件 |
| `_get_bytecode()` | 获取字节码（javap） |

## 关键技术点总结

### 1. subprocess 使用模式

```python
# 执行命令并捕获输出
result = subprocess.run(
    ['command', 'arg1', 'arg2'],
    cwd='/working/directory',
    capture_output=True,
    text=True
)

# 检查结果
if result.returncode == 0:
    output = result.stdout
else:
    error = result.stderr
```

### 2. 临时文件管理

```python
# 创建临时目录
temp_dir = tempfile.mkdtemp()

try:
    # 使用临时目录...
finally:
    # 确保清理
    shutil.rmtree(temp_dir)
```

### 3. XML解析

```python
import xml.etree.ElementTree as ET

tree = ET.parse('file.xml')
root = tree.getroot()

# 查找元素
for element in root.findall('.//dependency'):
    group_id = element.find('groupId').text
```

### 4. 异步函数

```python
async def my_async_function(param: str) -> dict:
    # 可以使用 await 调用其他异步函数
    # 或执行同步代码
    return {"result": "value"}
```

## 实践: 如何配置这个MCP工具

### Step 1: 安装依赖

```bash
pip install mcp
```

### Step 2: 安装反编译器（可选但推荐）

```bash
mkdir -p ~/tools
# 下载 CFR
curl -L -o ~/tools/cfr.jar https://github.com/leibnitz27/cfr/releases/download/0.152/cfr-0.152.jar
```

### Step 3: 在IDE中配置MCP

不同IDE配置方式不同，通常需要指定：
- MCP服务器启动命令
- 工作目录

例如在 Windsurf/Cursor 中的配置可能类似：

```json
{
  "mcpServers": {
    "maven-class-explorer": {
      "command": "python",
      "args": ["/path/to/maven_class_explorer.py"],
      "cwd": "/your/project/path"
    }
  }
}
```

### Step 4: 测试

在IDE中让AI助手尝试查找一个类：

```
"请帮我看看 org.springframework.core.SpringVersion 类的实现"
```

AI应该会调用 find_class 工具并返回反编译的源代码。
