# 06 - 反编译机制详解

## 概述

找到 `.class` 文件后，需要将其转换为人类（和AI）可读的格式。这个工具提供了多种反编译策略。

## 反编译策略优先级

```
┌───────────────────────────────────────────────────────┐
│                 _decompile_class()                    │
└───────────────────────────────────────────────────────┘
                        │
                        ▼
┌───────────────────────────────────────────────────────┐
│  策略1: CFR 反编译器                                  │
│  java -jar ~/tools/cfr.jar class_file                 │
│  输出: 完整的Java源代码                               │
└───────────────────────────────────────────────────────┘
                        │
                    失败？
                        │
              ┌─────────┴─────────┐
              │是                 │否
              ▼                   ▼
┌─────────────────────────┐   ┌─────────────────┐
│ 策略2: Procyon 反编译器 │   │  返回源代码     │
│ java -jar procyon.jar   │   └─────────────────┘
└─────────────────────────┘
              │
          失败？
              │
    ┌─────────┴─────────┐
    │是                 │否
    ▼                   ▼
┌─────────────────┐  ┌─────────────────┐
│ 策略3: javap    │  │  返回源代码     │
│ 获取字节码      │  └─────────────────┘
└─────────────────┘
```

## _decompile_class() 代码分析

```python
def _decompile_class(self, class_file_path, class_path):
    """Try to decompile a class file to Java source code"""
    
    # 策略1: 尝试使用 CFR 反编译器
    try:
        result = subprocess.run(
            ['java', '-jar', os.path.expanduser('~/tools/cfr.jar'), class_file_path],
            capture_output=True,
            text=True
        )
        if result.returncode == 0 and result.stdout:
            return result.stdout
    except:
        pass
        
    # 策略2: 尝试使用 Procyon 反编译器
    try:
        result = subprocess.run(
            ['java', '-jar', os.path.expanduser('~/tools/procyon.jar'), class_file_path],
            capture_output=True,
            text=True
        )
        if result.returncode == 0 and result.stdout:
            return result.stdout
    except:
        pass
    
    # 如果都失败，返回 None，让调用者使用 javap
    return None
```

## 常用Java反编译器对比

| 反编译器 | 特点 | 输出质量 |
|---------|------|---------|
| **CFR** | 活跃维护，支持最新Java特性 | ⭐⭐⭐⭐⭐ |

## _get_bytecode() 方法

当反编译失败时，使用 `javap` 获取字节码：

```python
def _get_bytecode(self, class_file_path):
    """Get bytecode representation of a class file"""
    try:
        result = subprocess.run(
            ['javap', '-c', '-p', class_file_path],
            capture_output=True,
            text=True
        )
        if result.returncode == 0:
            return result.stdout
    except Exception as e:
        return f"Error getting bytecode: {str(e)}"
    
    return "Could not get bytecode"
```

### javap 参数说明

| 参数 | 含义 |
|------|------|
| `-c` | 输出反汇编的字节码指令 |
| `-p` | 显示所有成员（包括private） |
| `-v` | 详细信息（常量池等） |
| `-s` | 显示内部类型签名 |

## 为什么需要多种反编译策略？

```
场景1: 正常Java类
  → CFR 成功反编译 ✓

场景2: 混淆过的代码
  → CFR 可能失败
  → Procyon 可能成功 ✓

场景3: 非常规字节码
  → CFR 失败
  → Procyon 失败
  → javap 总是可用（至少能看到结构）✓
```

## 代码中的异常处理

```python
try:
    result = subprocess.run([...])
    if result.returncode == 0 and result.stdout:
        return result.stdout
except:
    pass  # 静默忽略异常，尝试下一个策略
```

**为什么用空的 except?**
- 反编译器可能不存在（FileNotFoundError）
- 反编译器可能崩溃（各种异常）
- 我们有备用方案，所以忽略错误继续尝试
