# 04 - 依赖加载机制详解

## 概述

`load_dependencies()` 方法是整个工具的核心，它负责获取项目的所有Maven依赖信息。

## 代码分析

```python
def load_dependencies(self):
    """Load dependencies from Maven POM file"""
    # 策略1: 首先尝试直接解析POM文件
    self.parse_pom_file()
    
    # 策略2: 如果没找到依赖，使用Maven获取有效POM
    if not self.dependencies:
        self.get_effective_pom()
        self.parse_effective_pom()
        
    # 策略3: 最后尝试从VSCode Java扩展读取
    if not self.dependencies:
        self.read_vscode_classpath()
        
    print(f"Loaded {len(self.dependencies)} dependencies")
    return self.dependencies
```

## 策略1: parse_pom_file() 详解

```python
def parse_pom_file(self, pom_path=None):
    # 默认使用工作空间下的 pom.xml
    if pom_path is None:
        pom_path = os.path.join(self.workspace_path, 'pom.xml')
    
    # 运行Maven命令获取依赖列表
    result = subprocess.run(
        ['mvn', 'dependency:list'],  # Maven依赖列表命令
        cwd=os.path.dirname(pom_path),  # 在pom.xml所在目录执行
        capture_output=True,  # 捕获输出
        text=True  # 以文本形式返回
    )
```

### Maven dependency:list 输出格式

```
[INFO] --- maven-dependency-plugin:3.1.2:list (default-cli) @ my-project ---
[INFO] The following files have been resolved:
[INFO]    org.springframework:spring-core:jar:5.3.20:compile
[INFO]    com.google.guava:guava:jar:31.1-jre:compile
[INFO]    org.slf4j:slf4j-api:jar:1.7.36:compile
```

### 解析输出

```python
for line in result.stdout.splitlines():
    line = line.strip()
    # 只处理包含compile的依赖行
    if ':' in line and '[INFO]' in line and 'compile' in line:
        # 格式: groupId:artifactId:packaging:version:scope
        parts = line.split('[INFO]')[1].strip().split(':')
        if len(parts) >= 4:
            group_id = parts[0].strip()      # org.springframework
            artifact_id = parts[1].strip()   # spring-core
            version = parts[3].strip()       # 5.3.20
            
            key = f"{group_id}:{artifact_id}"
            jar_path = self._get_jar_path(group_id, artifact_id, version)
            
            if jar_path:
                self.dependencies[key] = {
                    "groupId": group_id,
                    "artifactId": artifact_id,
                    "version": version,
                    "path": jar_path
                }
```

## 策略2: get_effective_pom() 详解

### 什么是Effective POM？

```
┌─────────────────────────────────────────────────────────┐
│                    你的 pom.xml                         │
│  <parent>spring-boot-starter-parent</parent>           │
│  <dependencies>                                         │
│    <dependency>spring-boot-starter-web</dependency>    │
│  </dependencies>                                        │
└─────────────────────────────────────────────────────────┘
                          │
                    Maven 合并
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                  Effective POM                          │
│  包含所有继承的配置:                                     │
│  - 父POM的配置                                          │
│  - BOM导入的版本管理                                     │
│  - 所有传递依赖                                          │
│  - 完整的版本号                                          │
└─────────────────────────────────────────────────────────┘
```

### 代码实现

```python
def get_effective_pom(self):
    # 创建临时文件存储effective POM
    temp_file = tempfile.NamedTemporaryFile(delete=False, suffix='.xml')
    temp_file.close()
    
    # 运行Maven命令生成effective POM
    result = subprocess.run(
        ['mvn', 'help:effective-pom', f'-Doutput={temp_file.name}'],
        cwd=self.workspace_path,
        capture_output=True,
        text=True
    )
    
    if result.returncode == 0:
        self.effective_pom = temp_file.name
```

## 策略3: read_vscode_classpath() 详解

VSCode的Java扩展会生成`.classpath`文件：

```xml
<!-- .vscode/.classpath -->
<classpath>
    <classpathentry kind="lib" path="M2_REPO/org/springframework/spring-core/5.3.20/spring-core-5.3.20.jar"/>
    <classpathentry kind="lib" path="M2_REPO/com/google/guava/guava/31.1-jre/guava-31.1-jre.jar"/>
</classpath>
```

```python
def read_vscode_classpath(self):
```

## _get_jar_path() 辅助方法

将Maven坐标转换为本地仓库路径：

```python
def _get_jar_path(self, group_id, artifact_id, version):
    """Convert Maven coordinates to local repository path"""
    # org.springframework -> org/springframework
    group_path = group_id.replace('.', '/')
    
    # 构建JAR文件名
    jar_name = f"{artifact_id}-{version}.jar"
    
    # 完整路径: ~/.m2/repository/org/springframework/spring-core/5.3.20/spring-core-5.3.20.jar
    jar_path = os.path.join(
        self.m2_repo,       # ~/.m2/repository
        group_path,         # org/springframework
        artifact_id,        # spring-core
        version,            # 5.3.20
        jar_name            # spring-core-5.3.20.jar
    )
    
    if os.path.exists(jar_path):
        return jar_path
    return None
```

### 路径转换示例

```
Maven坐标: org.springframework:spring-core:5.3.20
    ↓
group_path: org/springframework
artifact_id: spring-core
version: 5.3.20
jar_name: spring-core-5.3.20.jar
    ↓
完整路径: ~/.m2/repository/org/springframework/spring-core/5.3.20/spring-core-5.3.20.jar
```
