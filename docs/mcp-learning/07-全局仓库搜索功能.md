# 07 - 全局仓库搜索功能

## 概述

当在项目依赖中找不到类时，`search_all_repository()` 方法会在整个Maven本地仓库中搜索。

## 为什么需要全局搜索？

```
场景: 你想了解一个类，但它不在当前项目的依赖中

例如: 项目使用 spring-boot-starter-web
      但你想了解 spring-jdbc 中的类
      
      spring-jdbc 不在项目依赖中
      但可能存在于你的 ~/.m2/repository 中（之前其他项目下载过）
```

## 代码详解

### Step 1: 提取搜索关键词

```python
# 获取包路径的各个部分
package_parts = class_path.split('.')
# "org.springframework.jdbc.core.JdbcTemplate" 
# → ["org", "springframework", "jdbc", "core", "JdbcTemplate"]

search_terms = []

# 添加前几个部分作为搜索词
if len(package_parts) >= 3:
    search_terms.append(package_parts[0])  # "org"
    search_terms.append(package_parts[1])  # "springframework"
    search_terms.append(package_parts[2])  # "jdbc"
    
    if len(package_parts) >= 4:
        search_terms.append(package_parts[3])  # "core"
```

### Step 2: 使用find命令搜索JAR文件

```python
potential_jars = []

for term in search_terms:
    # 构建shell命令
    find_cmd = f"find {self.m2_repo} -name '*.jar' | grep -i {term}"
    
    try:
        result = subprocess.run(
            find_cmd,
            shell=True,  # 使用shell执行（支持管道）
            capture_output=True,
            text=True
        )
        if result.stdout:
            potential_jars.extend(result.stdout.splitlines())
    except Exception as e:
        print(f"Error searching for JAR files with term '{term}': {e}")
```

### Step 3: 去重

```python
# 不同关键词可能匹配到相同的JAR
# 使用 set 去重
potential_jars = list(set(potential_jars))
print(f"Found {len(potential_jars)} potential JAR files to search")
```

### Step 4: 在每个JAR中查找类

```python
for jar_path in potential_jars:
    try:
        # 列出JAR内容
        result = subprocess.run(
            ['jar', 'tf', jar_path], 
            capture_output=True, 
            text=True
        )
        
        jar_contents = result.stdout.splitlines()
        
        # 检查目标类是否在JAR中
        if class_file in jar_contents:
            print(f"类在Maven仓库中找到: {jar_path}")
            
            # 提取并反编译...
            # 返回结果
            
    except Exception as e:
        print(f"Error processing JAR {jar_path}: {e}")
```

## _extract_maven_coords() 辅助方法

从JAR路径反向提取Maven坐标：

```python
def _extract_maven_coords(self, jar_path):
    """Extract Maven coordinates from JAR path"""
    # 移除m2仓库前缀
    # /Users/xxx/.m2/repository/org/springframework/spring-jdbc/5.3.20/spring-jdbc-5.3.20.jar
    # → org/springframework/spring-jdbc/5.3.20/spring-jdbc-5.3.20.jar
    rel_path = jar_path.replace(self.m2_repo, '').lstrip('/')
    
    parts = rel_path.split('/')
    # ["org", "springframework", "spring-jdbc", "5.3.20", "spring-jdbc-5.3.20.jar"]
    
    if len(parts) >= 3:
        jar_file = parts[-1]      # spring-jdbc-5.3.20.jar
        version = parts[-2]       # 5.3.20
        artifact_id = parts[-3]   # spring-jdbc
        group_id = '.'.join(parts[:-3])  # org.springframework
        
        return f"{group_id}:{artifact_id}:{version}"
        # "org.springframework:spring-jdbc:5.3.20"
    
    return jar_path  # 无法解析时返回原路径
```

## 性能考虑

### 问题
全局搜索可能很慢：
- Maven仓库可能有几千个JAR文件
- 每个JAR都需要执行 `jar tf` 命令

### 优化策略
1. **关键词过滤**: 只搜索包含相关关键词的JAR
2. **短路返回**: 找到第一个匹配就立即返回
3. **去重**: 避免重复检查相同的JAR

```python
# 找到即返回，不继续搜索
if class_file in jar_contents:
    # ... 处理并返回
    return {
        "status": "success",
        ...
    }
```

## 搜索优先级回顾

```
find_class() 被调用
       │
       ▼
项目依赖中搜索  ←──── 最快（JAR数量有限）
       │
   找不到？
       │
       ▼
全局仓库搜索   ←──── 较慢（JAR数量可能很多）
       │
   找不到？
       │
       ▼
返回错误信息
```
